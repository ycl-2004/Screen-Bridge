# Screen Bridge v1.1.1 Release Notes

Screen Bridge v1.1.1 is a patch release that promotes the latest `main` branch
after v1.1.0. It keeps the Mac-to-iPad extended-display behavior unchanged,
updates the app version to `1.1.1 (3)`, and ships the current YC hand-drawn
branding across Mac, iPad, README, and the AppDESC product overview.

## Highlights

- Keeps the existing Mac sender, iPad receiver, pairing flow, transport routes,
  display streaming, recovery, and per-app audio behavior unchanged.
- Updates the Mac and iPad user-visible version to `1.1.1 (3)`.
- Uses the YC hand-drawn watercolor/paper icon with wine, denim, blush, and
  ochre accents across the Mac `.icns`, iPad AppIcon, and iconset.
- Refreshes the AppDESC marketing image and README product presentation to use
  the same visual direction.
- Keeps internal `BetterCast*` target names, bundle IDs, pairing identifiers,
  and `_yc-cast._tcp` unchanged for compatibility.

## Product and version identity

- Product name: `Screen Bridge`.
- GitHub repository: `ycl-2004/Screen-Bridge`.
- Git tag and release: `v1.1.1`.
- Mac and iPad bundle version: `1.1.1 (3)`.
- Mac asset: `Screen-Bridge-v1.1.1-macOS-universal.zip`.
- Internal `BetterCast*` targets, bundle IDs, Keychain IDs, and
  `_yc-cast._tcp` remain unchanged for compatibility.

## Mac download

The release ZIP contains `Screen Bridge.app` with both `arm64` and `x86_64`
slices. Its SHA-256 is:

```text
98126b74cc2e3cb9cebc8cce31eaccd5684d72fc5997b5f8ede68dc8a1a92b70
```

The app is ad-hoc signed with Hardened Runtime and is not notarized. It is a
self-use/preview build. On first launch, Control-click the app, choose **Open**,
and confirm the prompt. A general public installer still requires Developer ID
signing and Apple notarization.

## iPad receiver

No public IPA is published. The iPad receiver requires signing through Xcode
with an Apple Team and provisioning profile tied to the target device. A
Personal Team profile is short-lived and is not a public distribution mechanism.

## Verification

Observed on macOS 26.6.1 with Swift 6.3.3 and Xcode 26.6:

- `swift test`: 136 tests, 0 failures.
- Universal Release build: succeeded for `arm64` and `x86_64`.
- App bundle: `1.1.1 (3)`, macOS 14.0 minimum, ad-hoc signature verified with
  `codesign --verify --deep --strict`.
- ZIP integrity test passed; the package contains the refreshed `AppIcon.icns`.
- Signed iPad Debug build installed on the connected iPad Air 5 running iPadOS
  15.7 with a Personal Team profile whose `TimeToLive` is 7 days.
- Plist validation, shell syntax checks, and `git diff --check`: passed.

## Known boundaries

- The Mac app is not Developer ID signed or notarized.
- No public iPad IPA is included.
- Video and audio are designed for trusted local networks and are not
  independently encrypted end to end.
- The K5 source-provenance question in the repository audit still needs
  owner/legal evidence before unrestricted public redistribution.
