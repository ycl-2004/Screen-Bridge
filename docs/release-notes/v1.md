# Screen Bridge v1 Release Notes

Screen Bridge v1 is the first release under the spaced product name. It brings
the Mac sender, iPad receiver, version metadata, package names, documentation,
and GitHub release identity under one `v1` label.

## Highlights

- Turns a real iPad into a display-only extended or mirrored Mac display.
- Uses pairing-backed authenticated sessions over the local network.
- Supports Auto, required cable, AWDL, and infrastructure Wi-Fi route choices
  without silently falling back from strict modes.
- Keeps Mac input local while the iPad receives video and optional Chrome audio.
- Uses numbered/timed AAC packets, an eight-packet sender FIFO, and receiver
  rebuffering to make audio delivery bounded and more tolerant of underruns.
- Separates transport, video arrival, decode, renderer, and audio health so a
  static desktop or an audio-only stream does not hide a failed picture path.
- Simplifies Mac Settings and the iPad onboarding/status experience around the
  current self-use workflow.

## Product and version identity

- User-facing name: `Screen Bridge`.
- GitHub repository slug: `Screen-Bridge`.
- Git tag and release: `v1`.
- Mac and iPad bundle version: `1.0 (1)`.
- Mac release asset: `Screen-Bridge-v1.dmg`.
- Internal `BetterCast*` modules, bundle IDs, Keychain IDs, and
  `_yc-cast._tcp` remain unchanged for compatibility.

## Distribution boundary

The Mac DMG is a universal build signed with the owner's Apple Development
identity. It is intended for the owner's self-use workflow and is not notarized.
A general public installer still requires Developer ID signing, Apple
notarization, and a stapled ticket.

No iPad IPA is published. The current iPad workflow uses Xcode provisioning
tied to an Apple account and registered device; Personal Team profiles are
short-lived and are not a public distribution mechanism.

## Verification

Release verification covers the shared Swift tests, strict Swift build, iOS
device-target build, plist validation, Git diff checks, universal app binary,
code signature verification, DMG signature verification, and mounted-image
contents. Real network paths, Chrome audio on hardware, Developer ID
notarization, and third-party installation remain outside this release's
verification boundary.
